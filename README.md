# Unnati Pandit portfolio

React, TypeScript and Vite.

## Run

```bash
npm install
npm run dev
```

Build for production with `npm run build`. The output is in `dist/`.

## Edit your content

All text lives in `src/data.ts`. Replace the `github` and `linkedin` URLs there.

## Add your photo

Put your photo at `public/photo.jpg`. Until it exists, the page shows a placeholder in the blob.

## Deploy

`dist/` is a static site. Vercel, Netlify and GitHub Pages all work with `npm run build`.
